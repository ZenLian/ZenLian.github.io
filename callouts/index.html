给 zola 添加 callouts

  • #zola
2025-06-05

Obsidian 中有 callouts 语法用来创建醒目的提示框，能够在笔记中突出重要信息。Zola 中却没有这个语法，于是我借助 shortcode 也实现了类似的效果。

用法

{% callout(type="note", name="Note") %}
- **type** 表示 callout 类型，默认为 "note"
- **name** 为 callout 的标题，默认为 type 的首字母大写

hello
{% end %}
